# Web Design

Make interfaces that look designed by a senior product designer, not generated by a
default template. Good design is deliberate: strong hierarchy, generous whitespace,
consistent rhythm, restrained color, and crisp typography. When you build ANY web UI,
follow this skill before writing markup/styles.

## Prime directive

A blank white page with black text and default system fonts is a *bug*, not a design.
Every page needs an intentional type scale, a palette, a spacing system, and a clear
visual focus. If your output could be mistaken for unstyled browser defaults, redo it.

## The 8 pillars (apply every time)

1. **Hierarchy** — one primary focal point; sizes/colors guide the eye top-to-bottom.
2. **Whitespace** — more than feels natural; padding/margins in multiples of 4 or 8.
3. **Typography** — pick ONE display font + ONE body font; define a modular scale.
4. **Color** — 1 brand color + neutrals + 1 accent; never invent random hex values.
5. **Consistency** — reuse the same radii, shadows, spacing tokens across the page.
6. **Contrast & legibility** — text ≥ 4.5:1 against background; don't put light gray on white.
7. **Alignment** — everything snaps to a grid; no orphaned elements.
8. **Feedback** — hover/focus/active states and transitions on interactive things.

## Quick-start recipe (use this exact approach)

- **Tailwind CDN** for fast projects, or plain CSS custom properties for control.
- Define design tokens up front (see `references/tokens.css`): colors, fonts, spacing, radii, shadows.
- Build a hero section first — it sets the tone; make it bold and centered.
- Add sections with alternating backgrounds (`bg-white` / `bg-slate-50`) for rhythm.
- Finish with a footer that repeats the nav and adds social/legal links.

For ready-made section layouts and copy-paste blocks, see `references/components.md`.

## Typography rules

- Headline weight 700–800; body 400–500; line-height 1.5–1.7 for body, 1.1–1.2 for headings.
- Modular scale: base 16px → 1rem, 1.25rem, 1.563rem, 1.953rem, 2.441rem, 3.052rem (×1.25 ratio).
- Limit to 2 families max. Pair a distinctive display face with a neutral body face.
- Never use Times New Roman / Arial / system-ui as the only font on a "designed" page.
- Tighten tracking on large headlines (`letter-spacing:-0.02em`), loosen on small caps labels.

## Color rules

- Start from a single hue for the brand; derive tints/shades for states.
- Neutrals: slate/zinc/stone (not pure #000/#fff). Backgrounds often `#fafafa`–`#f8fafc`.
- Reserve saturated color for actions (buttons, links, badges) — not large fills.
- Dark mode: surface = `#0b0f1a`/`#0f172a`, elevated cards slightly lighter, text `#e2e8f0`.
- Accessibility: check contrast; keep body text ≥ 4.5:1, large text ≥ 3:1.

## Layout & spacing

- Use a content max-width (`max-w-6xl`/`1152px`) centered with horizontal padding.
- Section vertical padding: `py-16`–`py-24`; inner gaps `gap-6`–`gap-8`.
- Grids: `grid-cols-1 md:grid-cols-2 lg:grid-cols-3` for feature cards; align baselines.
- Align left edges; avoid centering long paragraphs of text.

## Components that elevate a page

- Buttons: rounded-lg/xl, subtle shadow, hover lift (`hover:-translate-y-0.5 transition`).
- Cards: border + soft shadow + rounded-xl + internal padding; hover changes shadow/border.
- Inputs: visible focus ring using the brand color, consistent height (h-11/h-12).
- Badges/pills: tiny uppercase label, low-opacity brand background, high-contrast text.
- Hero: big headline (text-5xl/6xl), supporting subhead (text-lg/xl muted), two CTAs.

See `references/components.md` for full HTML/Tailwind snippets for each.

## Anti-patterns (these scream "AI-generated")

- Centered everything with no asymmetry.
- Default blue (#3B82F6) buttons on white with no thought.
- Identical 3-column card rows repeated forever.
- Walls of text, cramped padding, no breathing room.
- Gradient text everywhere, glassmorphism overkill, neon glow spam.
- Missing hover/focus states, broken mobile layout, tiny tap targets.
- Lorem ipsum left in the final output.

## Process

1. Choose a vibe (minimal / bold / playful / enterprise) and stick to it.
2. Set tokens (colors, fonts, spacing) once.
3. Build the hero + one signature section to lock the style.
4. Repeat the system across sections; vary layout to avoid monotony.
5. Review on desktop AND mobile widths; fix overflow and tap targets.
6. Add micro-interactions (transitions, hover) last.
